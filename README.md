# LinkPrice Integrated Advertising Proposal

GitHub Pages 배포용 정적 웹 제안서입니다.

## 구성
- NAVER SA
- NAVER GFA
- COUPANG
- 추가매체 · MOBION
- LinkPrice 통합 운영 모델

## 사용 방법
1. 이 폴더의 `index.html`을 GitHub 저장소 루트에 업로드합니다.
2. GitHub Pages에서 `Deploy from a branch`를 선택합니다.
3. `main / root`를 지정하면 바로 배포할 수 있습니다.

## 조작
- 키보드 ← / → : 페이지 이동
- 목차 버튼 : 전체 페이지 점프
- 전체화면 버튼 : 발표 모드
- PDF 버튼 : 브라우저 인쇄/PDF 저장
- 모바일 : 좌우 스와이프
